 H5P Single Choice Set
=====================

Allows you to create sets of single choice tasks.

## Development

The runtime is implemented in TypeScript with Lit and bundled as a classic H5P
preloaded script.

```sh
npm install
npm run typecheck
npm test
npm run build
```

The H5P runtime bundle is generated at `dist/single-choice-set.js`.
